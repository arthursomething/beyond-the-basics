# Beyond the Basics — course landing page

Landing page for a 37-hour live Figma cohort for product designers, built by Arturo Cuevas Sánchez.

Static site — plain HTML, CSS and JS, no build step. Open `index.html` directly or serve the folder with any static file host.

## Structure

- `index.html` — page markup
- `styles.css` — all styling (dark, grayscale, gradient design system)
- `script.js` — interactive state: curriculum phase/module browser, pricing track/pace matrix, module detail sheet, scroll reveals, contact form

## Deploying

This repo is set up to serve via GitHub Pages from the `main` branch root. To connect a custom domain, add a `CNAME` file at the repo root containing the domain, and point the domain's DNS at GitHub Pages per [GitHub's custom domain docs](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site).
